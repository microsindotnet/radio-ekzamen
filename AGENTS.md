# AGENTS.md

## Git

Все фиксации изменений выполняет **только пользователь**.

Агенту запрещено выполнять:

- `git add`
- `git commit`
- `git commit --amend`
- `git push`
- любые другие команды, изменяющие состояние репозитория (merge, rebase, reset, stash и т. п.)

Агент может выполнять только команды чтения: `git status`, `git diff`,
`git log`, `git show` и подобные.

Подготовленные изменения агент оставляет в рабочем дереве; добавляет и
фиксирует их пользователь самостоятельно.

## Проект

Тренажёр экзаменационных билетов на Python (см. `README.md`).

- `main.py` — точка входа.
- `src/tickets.py`, `src/answers.py` — данные билетов.
- `src/stat.py` — статистика ошибок (`err_stat.txt`).
- `src/picview.py` — просмотр картинок.
- `src/media/` — картинки билетов.
